Section B · Files developed

What was built in ml/

Each file is additive. The dataset pipeline remains the source of truth; the ML layer consumes its processed outputs.

01 · DATASET ANALYSIS
ml/preprocessing/dataset_analysis.py

Profiles the existing dataset package from an ML perspective and produces the Week 1 dataset analysis reports.

  • Profiles raw, processed, and training tables: rows, columns, missingness, duplicates, keys, and targets.
  • Summarises graph structure, splits, feature dimensions, and logistics feature coverage.
  • Writes datasets/reports/ml_dataset_analysis.json and .md.
  • Read-only with respect to source datasets; restricted CC BY-NC material is excluded.
02 · BASELINE EXPERIMENTS
ml/models/baseline_model.py

Runs scikit-learn feasibility baselines for the two shipment-delay tasks using existing leakage-safe features and reproducible splits.

  • Binary Smart Logistics task: 1,000 records, 10 features, 700/150/150 split.
  • SynDelay 3-class task: 155,488 records, currently only 2 usable features.
  • Model: HistGradientBoostingClassifier with fixed seed 42.
  • Writes ml/artifacts/baseline_metrics.json and datasets/reports/ml_baseline_report.md.
03 · INFERENCE CONTRACT
ml/inference/predict.py

Defines and validates the backend-facing prediction record. It formats a score; it does not generate predictions.

  • Validates non-empty company_id, score in [0, 1], and risk level LOW / MEDIUM / HIGH.
  • Keeps prediction_status = experimental until a labelled evaluation is approved.
  • Provides a stable JSON contract for backend integration once a trained model artifact exists.
  • No fake predictions and no fabricated risk scores.
04 · DOCUMENTATION
ml/README.md

The Week 1 technical report: scope, data findings, feature design, graph preprocessing, model recommendation, methodology, and limitations.

  • Documents the ML folder layout and dependency installation.
  • Records actual graph and dataset statistics with caveats.
  • Explains leakage controls, GNN architecture recommendation, and evaluation plan.
  • Includes the Week 1 deliverables checklist and known blockers.
Supporting modules

feature_engineering.py

Builds 18 numeric + 3 categorical + 128 embedding dimensions = 146 node features, plus 12 edge features. Fits scalers on the training split only.

graph_preprocessing.py

Builds the PyG Data object, validates finite values and index ranges, and runs the forward-pass smoke test.

gcn_model.py

Prototypes AtmoGCN, AtmoGraphSAGE, and AtmoGAT. No GNN training metrics are claimed.

Section F · Dataset limitations

Known gaps and blockers

These limitations are documented in the Week 1 reports. They constrain what can honestly be claimed.

SynDelay feature gap

High

The processed logistics_features.csv exposes only latitude and longitude for SynDelay. The raw file has 41 columns, but the other features were not carried into the combined feature table.

3-class baseline is a pipeline-gap check

High

With only two geographic features, the SynDelay baseline predicts the majority class for nearly every row: accuracy 0.5769, macro F1 0.2441, ROC-AUC 0.5064. It is not a credible predictive model.

Smart Logistics provenance unknown

Medium

The 1,000-row file was supplied locally. Its source, collection method, real/synthetic status, and licence are unconfirmed. Results are preliminary only.

No verified company-level risk labels

Blocker

training/risk_labels.csv marks all 130,020 nodes as not_available. No company-level disruption-risk model can be trained or evaluated on the current package.

No real disruption-risk model in Week 1

Scope

Week 1 delivered dataset analysis, feature preparation, graph loading, PyG validation, model prototypes, a prediction contract, and delay baselines. No GNN was trained, and no disruption-risk accuracy or risk level is claimed. The GNN prototypes are architecture scaffolding, not trained production models.

Additional caveats
Graph fragmented: 23,198 components Largest component: 40.4% of nodes Embedding coverage: 24.0% IC-SPLC and AnonNet are anonymised No cross-source entity resolution AnonNet and SynDelay have no LICENSE file GDELT is an 8-day, unverified news sample Restricted CC BY-NC assets excluded
